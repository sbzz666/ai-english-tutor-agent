# Mia English

面向小学生的 AI 英语学习应用，使用 TypeScript、React/Next.js 和 DeepSeek API。

目前覆盖 1–6 年级，每个年级 7 个主题，共 42 个主题、264 条单词卡。切换年级后，单词、例句、复习和学习进度会随之切换。该词库按小学英语常见主题独立编写，供“人教版一年级起点”方向的学生拓展记词；**不是教材逐课同步词表**，也不应被当作人教版官方完整词表。若要精确匹配所用教材，请提供书籍版本、册次和目录/词表。

现在以记单词为主：每课有单词卡、发音和例句；点击单词卡上的播放按钮会先读单词再读例句，点击例句可单独播放。点击“学会了，继续”会自动进入下一个单词并播放该词和例句，学完一组会直接进入下个主题。页面上方也保留主题选择，可随时自由切换；切换主题会从该主题第一词开始，原有学习记录不会清除。

学过的词会加入间隔复习：首次学习后次日出现，记住后依次延长至 3、7、14、30 天；暂时没记牢的词会在本轮再次出现。页面显示今日到期复习量，每轮最多 10 个词，先回想中文提示，再揭晓英文与例句。没有到期任务时可额外巩固已学词。现阶段提醒和进度仅保存在当前浏览器中，不提供系统推送或跨设备同步。

顶部搜索框可在所有年级的现有课程词库中按英文或中文检索，并跳转到单词卡。搜索范围是当前课程词库，不是联网的完整英语词典。

## 本地运行

1. 安装 Node.js 22 LTS。
2. 复制 `.env.example` 为 `.env.local`，填写 `DEEPSEEK_API_KEY`。
3. 运行 `npm install`和 `npm run dev`。

没有 API Key 时仍可使用内置回复演示。语音识别建议使用 Chrome 或 Edge，并允许麦克风权限。

## Windows 桌面版

GitHub Releases 提供可选安装目录的 `Setup.exe` 和解压即用的 `Portable.zip`。桌面版内置运行环境，用户无需安装 Node.js；学习进度保存在软件自己的本地数据目录中。

发布包不包含 DeepSeek API Key，未配置密钥时自动使用内置教学回复。推送 `v*` 标签会触发 GitHub Actions 自动构建发布。
